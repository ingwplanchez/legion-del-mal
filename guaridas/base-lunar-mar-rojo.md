# Base Lunar-Mar Rojo

- La base lunar está ubicada en la cara oculta de la Luna.
- La base cuenta con 5 niveles.
- El nivel 1 es el nivel de acceso.
- El nivel 2 es el nivel de control.
- El nivel 3 es el nivel de mando.
- El nivel 4 es el nivel de investigación.
- El nivel 5 es el nivel de seguridad.
